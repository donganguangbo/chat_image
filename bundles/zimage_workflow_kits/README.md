# Z-Image Workflow Kits

This directory contains two standalone kits for the **current** pipeline only:

- `zimage_t2i/`: Z-Image text-to-image (RedCraft stage1 + DarkBeastZ6 stage2)
- `zimage_edit/`: Z-IMAGE lock-edit (RedCraft stage1 + DarkBeastZ6 stage2 + ReActor/FaceDetailer)

Each kit contains:

- a workflow JSON copy under `workflows/`
- a dedicated `download_models.sh`
- a local README with usage notes
